# Notas por idioma

Punto de partida para el `glossary.md` de cada idioma. La Biblia del paquete manda sobre estas notas: si dice otra cosa, se sigue la Biblia y se anota en la bitácora.

**Calidad esperada** (avisar al usuario antes de empezar):
- **A**: traducción de calidad profesional.
- **B**: buena, conviene una lectura de un hablante.
- **C**: necesita revisión de un nativo antes de publicar; proponer dejar el inglés.
